# Lalynk Frontend

Frontend application for Lalynk, a secure secret-sharing platform.

## Tech Stack

- React
- TypeScript
- Vite

## Overview

The frontend provides the user interface for creating and retrieving one-time secrets and communicates with the Lalynk backend through a REST API.

## Configuration

The backend API URL is configured using the `VITE_API_URL` environment variable.

See the [Lalynk Backend](https://github.com/Lalynk/lalynk-backend) repository for the backend implementation.
